# Groundwater Drawdown Tool — Installation

Full installation and usage instructions are published here:

**<https://bcgov.github.io/groundwater-drawdown-tool/user-guide/>**

## In short

1. Download `setup.bat` from the latest release:
   <https://github.com/bcgov/groundwater-drawdown-tool/releases/latest/download/setup.bat>
2. Double-click `setup.bat` to install — or to update an existing
   install.
3. Double-click `run.bat` in the install folder to start the tool. Your
   browser opens to `http://localhost:8050`.

To **run an analysis** you must be on the BC government network, or
connected by VPN if working from home. First-time setup and updates do
not need the government network.

For step-by-step instructions and troubleshooting, see the
[User Guide](https://bcgov.github.io/groundwater-drawdown-tool/user-guide/).
